# Portfolio

## Présentation

Portfolio personnel présentant mon parcours professionnel, mes compétences et mes réalisations.
Ce projet s'inscrit das ma démarche de reconversion vers le développement web.

## Technologies utilisées

- HTML5 : structure et contenu
- CSS3 : mise en page et responsive design
- JavaScript : navigation et interactions

## Fonctionnalités

- Navigation interactive entre les sections
- Affichage responsive adapté aux différentes tailles d'écran
- Présentation des réalisations avec accordéon
- CV interactif avec filtrage des rubriques
- Consultation et téléchargement du CV au format PDF
